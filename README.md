# Personal Portfolio Website

## 📌 About the Project
This is a personal portfolio website developed using HTML, CSS, and JavaScript.
It showcases my personal information, technical skills, projects, and contact details.

The website provides a simple, modern, and responsive design to present my profile professionally.

## 🎯 Objectives
- Create a professional online portfolio.
- Showcase my technical skills and projects.
- Practice frontend web development.
- Build a responsive and user-friendly website.

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality

## ✨ Features
- Home section with personal introduction
- About Me section
- Technical Skills section
- Projects showcase
- Contact information
- Responsive layout
- Interactive Contact Me button
- Automatic copyright year

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the index.html file in a web browser.
4. Explore the different sections of the portfolio.
